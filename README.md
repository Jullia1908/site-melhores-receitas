# Melhores Receitas

Site de receitas desenvolvido durante o ensino médio com HTML e JavaScript. A página permite preencher um formulário e interagir com o conteúdo diretamente no navegador.

## Tecnologias

- HTML5
- JavaScript
- Bootstrap carregado por CDN

## Como visualizar

Abra o arquivo `index.html` em um navegador ou acesse a versão publicada:

https://jullia1908.github.io/site-melhores-receitas/

## Observação

O projeto funciona somente no navegador. As informações preenchidas não são enviadas para um servidor nem ficam armazenadas depois que a página é fechada.

## Contexto

Este projeto foi criado como exercício de aprendizagem para praticar formulários, manipulação da página com JavaScript e componentes do Bootstrap.
